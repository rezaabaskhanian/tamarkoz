# آزمون‌های دستی روی گوشی

## پیش از اولین ساخت
- اگر کلید بازار را داری: `BAZAAR_RSA_KEY=...` در `android/gradle.properties` (بدون آن خرید خطای «تنظیم نشده» می‌دهد).
- ساخت: `npm run android`. بار اول codegen کلاس‌های `com.tamarkoz.specs.NativeFocusSpec` و `NativeBillingSpec` را می‌سازد.

## حالت‌های لبه (از برگه‌ی مشخصات)
- [ ] خاموش/روشن شدن گوشی وسط جلسه → ادامه با آخرین زمان ذخیره‌شده
- [ ] تغییر ساعت/تاریخ گوشی → زمان باقی‌مانده تغییر نکند
- [ ] بستن سرویس توسط سیستم → حداکثر ۵ دقیقه بعد برگردد
- [ ] به‌روزرسانی اپ وسط جلسه → سرویس دوباره بالا بیاید (MY_PACKAGE_REPLACED)
- [ ] لغو مجوز اجباری وسط جلسه → broken + اعلان «قفل از کار افتاد»
- [ ] تماس ورودی → تماس باز، زمان‌سنج ادامه
- [ ] جلسه از نیمه‌شب بگذرد → برای روز شروع حساب شود
- [ ] گوشی هنگام شروع نوبت خاموش → تا ۱۰ دقیقه: شروع با همان ساعت پایان؛ دیرتر: missed
- [ ] تغییر منطقه‌ی زمانی → هشدارها دوباره محاسبه شوند
- [ ] دو بار پشت سر هم «شروع» → فقط یک جلسه
- [ ] اپ ممنوع حذف شده → از فهرست پنهان، بدون خطا
- [ ] پایان اعتبار خرید وسط جلسه → جلسه ادامه یابد
